# Maven Market Performance Dashboard 📊

## 📌 Project Overview
This repository contains a dynamic and interactive **Power BI Dashboard** developed for **Maven Market**. The objective of this project is to analyze global sales performance, evaluate profit margins, monitor product brand metrics, and track monthly target achievements.

---

## 📈 Key Metrics & Insights
* **Total Transactions:** 167,616
* **Total Profit:** $6.61M+
* **Average Profit Margin:** 59.93%
* **Low Return Rate:** 0.99% overall average
* **KPI Goal Achievements:** Exceeded current month targets for both transactions (+5.69%) and overall profit (+5.61%).

---

## 🔍 Visualizations & Features Included
* **Topline KPIs:** Live tracking of transactions, profit, and revenue against set targets.
* **Geographic Breakdown:** Interactive map and treemap visualising store performance across **USA, Mexico, and Canada**.
* **Brand Matrix:** Comprehensive brand-level analysis (e.g., Hermanos, Tell Tale, Ebony) showing total transactions, profit margins, and return rates.
* **Revenue Trending:** Weekly sales trend analysis to monitor revenue patterns over time.

---

## 🛠️ Tech Stack & Tools
* **BI Tool:** Power BI Desktop
* **Data Transformation:** Power Query
* **Analytics & DAX:** Measure calculations for Profit Margins, Target Variance %, and Return Rates.

---

## 🚀 How to Run the Project
1. Clone this repository or download the `.pbix` file.
2. Open the file in **Power BI Desktop**.
3. Interact with slicers (e.g., Country Filter) to explore filtered data.
